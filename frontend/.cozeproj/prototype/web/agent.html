Agent 基础概念与架构设计

理解 AI Agent 的核心定义、与传统 Chatbot 的区别，掌握 ReAct、Plan-and-Execute 等主流 Agent 架构模式。学习 Agent 的感知-推理-行动循环，建立对智能体系统的全局认知。

Agent 架构 ReAct Prompt Engineering

LangChain LCEL Chain
进阶 10 节课

RAG 检索增强生成实战

从文档解析、文本分块到向量嵌入，完整构建 RAG 流水线。学习 ChromaDB、FAISS 等向量数据库的使用，掌握混合检索、重排序、查询改写等高级优化策略，让 Agent 具备精准的知识问答能力。

RAG ChromaDB 向量检索 Embedding
进阶 8 节课

LangGraph 状态机与图编排

学习使用 LangGraph 构建有状态的 Agent 工作流。掌握节点、边、条件路由的核心概念，实现循环推理、人机协作、断点恢复等高级特性。对比 LangChain Agent 与 LangGraph Agent 的适用场景。

LangGraph State Machine Workflow
进阶 7 节课

Tool Use 与函数调用机制

深入理解 Function Calling 的底层原理，学习为 Agent 定义和注册自定义工具。掌握工具描述规范、参数校验、错误处理，实现 Agent 与外部 API、数据库、文件系统的无缝交互。

Function Calling Tool Use API 集成
高级 9 节课

多 Agent 协作系统设计

探索多 Agent 系统的协作模式：层级式、对等式、竞争式。使用 AutoGen 和 CrewAI 框架构建多 Agent 团队，实现任务分解、角色分配、结果汇总。学习 Agent 间通信协议与冲突解决策略。

多Agent AutoGen CrewAI 协作模式
进阶 6 节课

Agent 记忆与上下文管理

掌握 Agent 的短期记忆、长期记忆与情景记忆机制。学习对话历史压缩、摘要记忆、知识图谱记忆等实现方案。解决长对话中的上下文丢失问题，让 Agent 具备真正的持续学习能力。

Memory Context Window 知识图谱
高级 8 节课

Agent 部署与生产实践

将 Agent 从开发环境推向生产。学习使用 Dify 低代码平台快速搭建 Agent 应用，掌握 Docker 容器化部署、API 网关配置、日志监控与成本优化。了解 Agent 的安全防护、幻觉治理与评估体系。

Dify Docker 监控 生产部署
