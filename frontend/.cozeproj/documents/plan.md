# 原型视觉风格修正计划

## 概述

将学习平台原型的**视觉风格**从"SaaS 仪表盘"调整为**技术博客风格**，参考 lololowe.com 的设计元素。保持现有布局结构（侧边栏+顶栏）和功能不变，仅调整视觉元素的呈现方式。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 修正范围 | 仅视觉风格 | 用户明确要求风格贴近，不改变结构 |
| 参考目标 | lololowe.com 博客风格 | 用户指定 |
| 保持不变的 | 布局结构、功能模块、页面数量 | 用户只要求风格调整 |

## 风格差异分析

| 元素 | 当前原型（SaaS风格） | 目标风格（博客风格） |
|------|---------------------|---------------------|
| **课程卡片** | 进度条+统计数字为主 | 封面图+标题+摘要+标签，类似文章卡片 |
| **标签/分类** | 小圆角标签 | 彩色分类标签，类似博客的分类/Tag样式 |
| **首页布局** | 统计卡片+进度概览 | 课程"文章流"为主，类似博客首页的文章列表 |
| **侧边栏小组件** | 学习进度条 | 类似"小板报"的学习统计、标签云、推荐课程 |
| **排版节奏** | 紧凑、信息密度高 | 松散、阅读友好、留白充足 |
| **整体氛围** | 工具/仪表盘 | 技术博客/知识库 |

## 功能模块（保持不变）

8 个页面的功能结构不变，仅调整视觉呈现：
- home.html：课程以"文章卡片流"展示，而非仪表盘
- rust.html / algorithm.html / agent.html：课程列表改为博客式卡片
- course-detail.html：已接近博客文章页，微调
- practice.html / learning-path.html / profile.html：保持功能，调整视觉

## 是否有原型设计

是

## 实施步骤

### 阶段一：原型风格修正

1. **修正骨架 Design Token** — 调整配色和圆角，让整体更偏博客的清新感。涉及文件：`_skeleton.html`

2. **修正首页 home.html** — 将仪表盘风格改为博客式"课程文章流"：课程卡片加封面图、摘要、标签；去掉过多统计进度条；加入类似"小板报"的学习日历组件。涉及文件：`home.html`

3. **修正三个学习方向页** — rust.html / algorithm.html / agent.html 的课程卡片改为博客文章卡片样式（封面图+标题+分类标签+摘要+日期），去掉SaaS化的统计概览。涉及文件：`rust.html`、`algorithm.html`、`agent.html`

4. **修正其余页面** — course-detail.html 微调标签和排版；practice.html / learning-path.html / profile.html 调整视觉元素使其更贴近博客风格。涉及文件：`course-detail.html`、`practice.html`、`learning-path.html`、`profile.html`

5. **用户验收原型** — 提示用户在画板中查看修正后的效果，确认后进入开发阶段

### 阶段二：代码开发与文档编写

6. **初始化 Next.js 项目并开发前端** — 根据修正后的原型实现前端代码，迁移 Design Token 到 globals.css。涉及文件：`src/app/globals.css`、各页面组件

7. **编写接口文档 API_SPEC.md** — 定义前后端 API 契约。涉及文件：`documents/API_SPEC.md`

8. **编写数据库设计文档 + Agent 文档 + AGENTS.md** — 数据库选型、表结构设计、Agent 集成方案、项目总索引。涉及文件：`documents/DATABASE_DESIGN.md`、`documents/AGENT_DESIGN.md`、`AGENTS.md`

##### @page(/) 首页

**核心职责**：以博客文章流的形式展示课程推荐和学习动态。
**访问路径**：导航直达。
**布局**：顶栏 + 左侧导航 + 主内容区（课程卡片流 + 右侧小组件栏）。

**主内容区**：
- 顶部简短欢迎语（非统计仪表盘）
- 课程卡片流：每个卡片包含封面图、分类标签（Rust/算法/Agent）、标题、摘要（2行）、作者、日期、阅读量，类似博客文章卡片
- 右侧小组件栏：学习日历（类似小板报）、标签云、推荐资源
